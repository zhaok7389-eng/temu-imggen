## 1. 目标

输入一个美妆 SKU 的产品图，输出一套 8 张 1:1 英文主副图，可直接用于 Temu 美区上架，并附带验收结果、成本记录和 ERP 导入表。

成功标准（v1 定稿时）：
- 11 个测试产品全部跑通，每套都有可用的 8 张图（自动 + 人工修复后）。
- 包装大字错误：最终交付图 0 处。
- 新增文案：只来自已确认的包装文字，拼写 0 错误。
- 连续 1 小时 ≥ 20 套（含自动验收和修复，不含人工审核）。
- 用户能独立完成"导入 → 导出"全过程。

## 2. 范围

做：
- 本地网页工具（在用户电脑上运行，浏览器打开）。
- 标签转录、套图计划、生成、自动验收、自动修复、人工审核、导出。
- 多店铺变体（同一 SKU 出 2–3 套有区别的图）。
- 成本与耗时记账。

不做（v1）：
- 自动上架、店铺数据回传、点击率分析。
- 多用户账号、权限、云端部署。
- 视频、详情长图。

## 4. 运行环境

- Python 3.11+，macOS / Windows 均可（待用户确认系统）。
- 后端 FastAPI + SQLite；前端轻量（原生 JS 或 htmx），不需要构建工具。
- 依赖：openai、pillow、opencv-python、rapidocr-onnxruntime、rembg（BiRefNet 模型）、mediapipe、openpyxl、pydantic。
- 启动：`python app.py`，自动打开 `http://127.0.0.1:8765`。只监听本机。

## 5. 功能需求

### F1 产品库
- 拖入文件夹：一个文件夹 = 一个 SKU；支持 jpg/png/webp，一个 SKU 可有多张产品图（不同颜色或角度）。
- SKU 状态：待转录 / 待确认 / 计划中 / 生成中 / 待审核 / 已导出 / 有问题。
- 列表可按状态筛选，显示每个 SKU 已花费用。

### F2 标签转录（第 0 步，最关键）
- 对每张产品图做文字识别，两路并行：
  - OpenAI 视觉模型：逐行转录，要求"原样照抄，含拼写错误，不纠正"，并标出每行的大致区域和字号级别（大/中/小）。
  - 本地 OCR（rapidocr）：给出文字框坐标。
- 两路结果对齐合并；不一致的行黄色高亮，由用户确认。
- 疑似拼写错误（词典外）的行，提示"按原样保留"，默认不改。
- 用户在页面上：
  - 确认或修改每一行（修改的是"识别错误"，不是包装错字）。
  - 勾选哪些说法可以作为卖点文案。
  - 填写：类目、件数、容量、尺寸（可空）、质地描述、用法步骤（可空，从标签自动带出）。
- 产出 `label.json`：
  ```json
  {
    "lines": [{"text": "Replenis h moisture to the skin", "size": "small", "bbox": [x,y,w,h], "image": "main.png"}],
    "big_text": ["zyzt", "RETINOL CREAM", "NET: 1.7fl.oz / 50g"],
    "allowed_claims": ["Replenishes Moisture"],
    "confirmed_at": "2026-11-14T10:00:00"
  }
  ```
- 每个 SKU 只需确认一次；以后重跑、加店铺变体都复用。

### F3 套图计划
- 调用 OpenAI 文本模型（型号在设置里选，取账号可用列表），输入 `label.json` + 类目模板 + 图位卡片 + 已用过的风格（避免多店铺重复），输出 `plan.json`。
- `plan.json` 包含：风格锁（主色、辅色、背景、光线、字体、道具、人物部位）、8 个图位各自的模板和文案。
- 程序校验（不过就重写，最多 2 次，再不过标红给用户）：
  - 所有文案能在 `allowed_claims` / 品名 / 容量 / 件数中找到；
  - 不含禁用词表；
  - 字数不超过图位上限；
  - 尺寸图在尺寸为空时自动跳过。
- 页面上可直接改文案和风格锁；显示预计费用。
- 店铺变体：选 N 个变体，每个变体不同的首图模板 + 风格锁 + 图位顺序。

### F4 生成
- 接口：images/edits；输入产品图（+ 可选风格参考图）；默认模型 gpt-image-2.5-flare，medium，1024×1024，png。
- 提示词 = 图位模板 + 风格锁 + 文案 + **标签原文块** + 保真指令：
  ```text
  The product label contains exactly this text, line by line. Reproduce it exactly, including misspellings:
  [1] zyzt
  [2] RETINOL CREAM
  [3] Reduce wrinkles, fine lines and crow's feet.
  ...
  Do not correct, translate or re-letter any of it.
  ```
- 模型路由（可在设置里改）：标签小字多（≥ 6 行）或有疑似错字的 SKU 用 2.5-sunburst；其余用 2.5-flare。以 T3 加测结果为准再定。
- 多格图（使用方法）：每格单独生成，再按版式拼图加编号和文字（Pillow 排字）。
- 并发：默认 6，可调；429/5xx 指数退避，最多 4 次；内容审核拦截不重试，记原文。
- 每次调用写账本：时间、SKU、变体、图位、第几次、模型、画质、tokens（文字入/图片入/输出）、费用、耗时、结果。tokens 取 API 返回的 usage，单价写在配置里。

### F5 自动验收
每张图生成 `qa.json`；硬指标任一不过即不过。

| # | 检查 | 方法 | 通过条件 |
|---|---|---|---|
| Q1 | 包装大字 | 抠出产品区域 → OCR → 与 `big_text` 比对 | 完全一致（忽略大小写和空格） |
| Q2 | 包装小字 | 同上，与 `lines` 中小字比对 | 字符相似度 ≥ 0.85；不过进修复，不直接判死 |
| Q3 | 新增文字 | 产品区域外 OCR → 与计划文案比对 | 逐字一致，无多余文字 |
| Q4 | 产品外形与颜色 | BiRefNet 抠图 → 与原图比轮廓和主色 | 轮廓相似度 ≥ 0.85，主色 ΔE ≤ 10 |
| Q5 | 件数 | 检测产品实例数量 | 与产品图一致（首图必须齐全；副图按计划） |
| Q6 | 产品占比 | 掩膜面积 / 画面 | 在图位区间内 |
| Q7 | 人物 | 人脸/手检测 + 视觉模型检查 | 人脸开关关闭时无完整人脸；手指数量正常；无明显 AI 畸形 |
| Q8 | 图位特殊项 | 例如尺寸图四周白色 ≥ 95% | 见版式规范卡 |
| Q9 | 美观分 | 视觉模型 1–5 分，并列出问题 | ≥ 3 分；只用于排序和提示 |

所有阈值写在配置文件里，11/16 用户人工标注后校准。

### F6 自动修复
按顺序尝试，每步后重新验收，通过即停；每个图位最多 3 次生成机会，仍不过就标红交人工。

1. **只是新增文字错**：抹掉该区域，用 Pillow 按计划字体重新排字；或 sunburst 局部编辑。
2. **包装文字错、外形对**：原标签回贴——
   - 在原产品图和生成图上分别抠出产品；
   - 特征点匹配（SIFT）求透视变换；
   - 把原图标签区域变换后贴到生成图，边缘羽化，按生成图光照做颜色匹配；
   - 回贴后再跑 Q1/Q2。
3. **外形也变了**：整体替换——保留生成图背景，把原产品抠图按生成图中产品的位置和大小放回，补投影和反光。
4. **以上都不行，或人物/美观问题**：重新生成，提示词带上失败原因。

### F7 审核墙
- 按 SKU 一行显示 8 宫格；标红的图显示原因。
- 点开单张：与原产品图并排、可放大看标签。
- 操作：通过（快捷键 A）、重出（R）、回贴标签（L）、局部修（框选 + 一句话，v1.1）。
- 批量操作：整套通过、整批通过未标红的。
- 记录用户的通过/否决，作为校准数据。

### F8 导出
- 文件名：`{sku_id}_{变体}_{图位两位数}.jpg`，JPG 质量 92。
- ERP 表（xlsx）：sku_id、变体、主图、副图 2–8、验收状态、费用。列名做成映射配置，拿到店小秘/芒果店长模板后只改配置。
- 每个 SKU 一张 8 宫格联系表。
- 打包为 zip。

### F9 设置
- API key 状态检测（只显示可用/不可用，不显示 key）。
- 每日预算、并发、默认模型和画质、模型路由规则、人脸开关、单价表。

### F10 模板库（v1 用 YAML 文件，v1.1 做页面）
- `slots.yaml`：8 个图位卡片。
- `categories.yaml`：类目首图模板 A/B。
- `banned.yaml`：禁用词与禁用元素。
- `refs/`：风格参考图。
- 内容来自《版式规范卡 v0》，用户审美调整都改这里。

## 10. 风险

| 风险 | 应对 |
|---|---|
| 小字识别不准，导致验收误判 | 两路识别 + 人工确认；小字不过先走回贴，不直接判死 |
| 斜角、手拿的图回贴不准 | 这类图位依赖原文提示词 + sunburst + 重出；仍不过人工处理 |
| 模型更新导致效果变化 | 配置里锁定模型版本；每次升级先跑 11 个产品回归 |
| 我的云端工作区连不上 OpenAI | 开发在云端写代码和离线测试；真实调用在你的机器上跑 |
| 人脸开放后合格率下降 | 人脸开关默认关，按类目逐步打开 |
